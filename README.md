# coding-train

Coding exercises and visual simulations inspired by The Coding Train.

## Projects

### 10bcount
A counter benchmark implemented in multiple languages:
- C, C++, Java, Python, Rust

### 1strafieldSimulation
A star field animation built with Pygame. Stars move toward the viewer at variable speed controlled by mouse position.

## Tech Stack

- Python (Pygame)
- C / C++ / Java / Rust

## Setup

```bash
# Star field simulation
cd 1strafieldSimulation
pip install pygame
python main.py
```

## Usage

Run any language variant in `10bcount/` to compare loop performance. Launch `main.py` in the simulation directory to view the animated star field.
